# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers services for computing, storage, databases, networking, security, analytics, and application development. AWS launched its first major public cloud services in 2006.

## Global Infrastructure

AWS uses a global infrastructure organized into Regions and Availability Zones. A Region is a separate geographic area, while Availability Zones are isolated locations within a Region. AWS designs its infrastructure to support highly available and fault-tolerant applications.

## Cloud Management Console

The AWS Management Console is a web-based interface used to create, configure, monitor, and manage AWS resources and services.

## Four Core Services

1. **Amazon EC2** – Provides virtual servers for running applications.
2. **Amazon S3** – Provides scalable object storage.
3. **Amazon RDS** – Provides managed relational databases.
4. **AWS IAM** – Manages identities, users, roles, and permissions.

## Three Advantages

1. AWS provides a very broad selection of cloud services.
2. AWS has a large global infrastructure.
3. AWS supports flexible scaling for applications ranging from startups to large enterprises.

## Typical Enterprise Use Cases

AWS can be used for web applications, mobile applications, enterprise systems, data storage, backup and recovery, databases, analytics, artificial intelligence, and global e-commerce applications.
