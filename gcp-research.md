# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is Google's cloud computing platform. It provides services for computing, storage, databases, networking, artificial intelligence, machine learning, analytics, and application development.

## Global Infrastructure

Google Cloud organizes its infrastructure into regions and zones. Regions are geographic areas, while zones are isolated locations within regions. Deploying resources across multiple zones or regions can help improve availability and protect applications from infrastructure failures.

## Cloud Management Console

Google Cloud Console is a web-based interface used to create, configure, monitor, and manage Google Cloud resources.

## Four Core Services

1. **Compute Engine** – Provides virtual machines.
2. **Cloud Storage** – Provides scalable object storage.
3. **Cloud SQL** – Provides managed relational databases.
4. **Google Kubernetes Engine (GKE)** – Provides managed Kubernetes clusters.

## Three Advantages

1. Strong artificial intelligence and machine learning capabilities.
2. Strong Kubernetes and container technologies.
3. Global infrastructure suitable for large-scale applications and data processing.

## Typical Enterprise Use Cases

Google Cloud can be used for artificial intelligence, machine learning, data analytics, web applications, Kubernetes deployments, databases, and large-scale data processing.
